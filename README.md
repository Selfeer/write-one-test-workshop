# Write one test, break a thousand ways

A 1-hour GeoSTQB workshop: how we test a distributed database (ClickHouse) with combinatorial tests,
using [clickhouse-regression](https://github.com/Altinity/clickhouse-regression) as the example.

- `index.html`: the deck. Open it in a browser; it works offline. Keys: → next, ← back, T theme, F fullscreen.
- `src/deck.html`: the deck source. Edit it, then run `python3 build.py` to rebuild `index.html`.
- `PLAN.md`: running order, exercises, demo prep, open items.
- `LINKS.md`: links to the suite code for each example in the deck.
- `BUG_STORIES.md`: real bugs found by combinatorial tests.
